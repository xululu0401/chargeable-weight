# 计费重对账台（chargeable-weight）

把要寄的每一件的**实重**与**长宽高**填进来，按你自己填的报价表算清：每件按几公斤**计费**（实重还是**体积重**说了算）、被体积重多收了多少、**拆成几个包裹寄最便宜**、全部合并成一件到底划不划算。分块方案是**精确枚举**（件数 ≤10、包裹数 ≤4 时枚举全部划分），不是贪心或估算。

- 在线体验：https://xululu0401.github.io/chargeable-weight/
- 单文件交付：`index.html`（内联 `core.js` 与 `ui.js`，无外部依赖、不联网）
- 测试：`node --test tests/core.test.cjs`
- 构建：`node build.cjs`（由 `template.html` + `core.js` + `ui.js` 生成 `index.html`）

口径见页面内「算法与使用边界」，与 `../需求与调研.md` 一致。默认样例的物品与费率均为**虚构示例**，不代表任何快递公司的实际报价。

边界：不做装箱、不查真实报价、不处理分区价/附加费/保价费；只做计费重与运费的算术对账。
